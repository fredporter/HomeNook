# HomeNest

Standalone Linux Steam gaming and media server with a controller-friendly
living-room console. HomeNest is its own product, not uCode3.

**Status: revival planned; existing implementation is not yet qualified.**
Steam gaming plus films/music/TV is the confirmed scope. Home Assistant/Matter
belongs to a separate integration repository with its own API, commands and
uihub card. uCore/uCode integration is optional; Sonic provisions the host and
installs independently versioned artifacts.
